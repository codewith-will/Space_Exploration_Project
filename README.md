# 🚀 Space Exploration Landing Page

A modern, responsive landing page built as part of the Scrimba Frontend Developer Path. This project focuses on modern CSS styling techniques, typographic hierarchy, asset optimization, and accessibility best practices.

## ✨ Key Features & Technical Implementation

* **Asset Optimization & Performance:** Replaced legacy JPEG assets with lightweight **WebP image formats** to reduce bundle size and improve page load speeds.
* **Advanced Typography:** Integrated Google Fonts alongside custom local **`@font-face`** declarations, keeping performance and usability trade-offs in mind.
* **Visual Polish & Readability:** Engineered custom **text shadows** to ensure high-contrast legibility over complex background imagery sourced from Unsplash.
* **Theming & Color Palettes:** Derived a cohesive, space-themed color palette directly from core imagery to establish a unified visual identity.
* **Semantic Structure & Accessibility:** Implemented proper HTML5 semantic elements, including the `lang` attribute and custom inline styling structures (using `span` elements) for localized underlines.

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic Structure)
* **Styling:** CSS3 (Flexbox, Custom Properties, `@font-face`, Text Shadows)
* **Assets:** WebP, Unsplash High-Resolution Imagery

## 💡 What I Learned

* **Performance-First Typography:** Evaluating the trade-offs of loading external fonts versus hosting custom fonts via `@font-face`, ensuring minimal layout shift and fast render times.
* **Modern Image Formats:** Understanding how switching to WebP drastically cuts down payload sizes for media-heavy web pages without sacrificing visual quality.
* **Contrast & UI Legibility:** Using text shadows and overlay techniques to solve common design friction points when text is placed directly over complex photographic backgrounds.
